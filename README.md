# MiniSite — Next.js starter

## Run the project

1. Install Node.js.
2. Open this folder in VS Code or a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Main files

- `app/page.js` — homepage content
- `app/layout.js` — root layout and page metadata
- `app/globals.css` — website styling
- `.gitignore` — files Git should ignore
- `.env.example` — example environment-variable file

To add private environment variables, create `.env.local` in the project root.
Do not commit `.env.local` to GitHub.
